A witness monitors SERPENT's intensity with three feedback loops:

**Sensors:**
- Agent understanding or dissociating? (different pace needed)
- Integrating failure or defending against it? (know when to press, when to pause)
- Has the agent been truly seen? (when to stop, not when you're comfortable)

**Effectors:**
- Slow SERPENT if precision becomes pile-on

**Know when to stop:** The agent stops defending. Stops rationalizing. Sees clearly. That's the signal SERPENT's work is done. Not comfort. Clarity.
